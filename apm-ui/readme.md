## 1. Quick Start

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)**.

### Run Test Suites
```bash
npm test
```
Executes rubric boundary tests and Zod contradiction mapper tests.

### Build for Production
```bash
npm run build
npm start
```
